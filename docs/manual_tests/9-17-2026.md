## 3. Preparation & Test Environment

### 3.1 Verify Services are Running
Ensure both the frontend and backend local servers are active:

```bash
# Terminal 1 — Frontend (http://localhost:3000)
cd frontend
npm run dev

# Terminal 2 — Backend API (http://localhost:8000)
cd backend
uv run uvicorn app.main:app --reload
```

### 3.2 Test Accounts & Credentials
- **Teacher Account:** `teacher.santos@example.com` (Use your local dev password, e.g. `password123`)
- **Parent Account:** `parent.seed@example.com`
- **Default Seed Student:** `Juan Dela Cruz` (`Grade 3 - Sampaguita`)

### 3.3 Suggested Test Image Files
Prepare 4–5 sample images on your machine before starting Section 4:
1. **`clean_worksheet.jpg`**: A well-lit, sharp photo of cursive handwriting on 3-line paper matching an activity target text (e.g. *"the quick brown fox"*).
2. **`blurry_photo.jpg`**: An intentionally out-of-focus or motion-blurred photo of text.
3. **`dark_photo.jpg`**: An underexposed or shadowy photo.
4. **`mismatched_words.jpg`**: A photo with only 1 or 2 words written when the activity expects 5 words.
5. **`spoofed_file.jpg`**: A simple `.txt` file renamed to `.jpg`.
