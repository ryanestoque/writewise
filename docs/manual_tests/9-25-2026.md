## 3. Preparation & Test Environment

### 3.1 Verify Services are Running
Ensure both the frontend and backend local servers are active in separate terminals:

```bash
# Terminal 1 — Frontend (http://localhost:3000)
cd frontend
npm run dev

# Terminal 2 — Backend API (http://localhost:8000)
cd backend
uv run uvicorn app.main:app --reload
```

> [!TIP]
> **Scoring Engine Configuration:** The backend defaults to `SCORING_ENGINE=manual` (Phase 1 behavior: submissions require teacher manual grading). To test Phase 2 automated scoring (Section 5, `TC-SCORE-10`), start the backend with `SCORING_ENGINE=calibrated`:
> ```bash
> SCORING_ENGINE=calibrated uv run uvicorn app.main:app --reload
> ```

### 3.3 Suggested Test Files & Hardware
Prepare the following on your test machine before starting Section 4:
1. **`clean_worksheet.jpg`**: A well-lit, sharp photo of cursive handwriting on 3-line paper matching an activity target text (e.g. *"the quick brown fox"*).
2. **`faint_pencil_worksheet.jpg`**: A legitimate cursive handwriting sample written with a standard #2 pencil with light/medium pressure (to verify the recalibrated contrast floor).
3. **`blurry_photo.jpg`**: An intentionally out-of-focus or motion-blurred photo of text.
4. **`dark_photo.jpg`**: An underexposed or shadowy photo.
5. **`mismatched_words.jpg`**: A photo with only 1 or 2 words written when the activity expects 5 words.
6. **`spoofed_file.jpg`**: A simple `.txt` file renamed to `.jpg`.
7. **`sideways_worksheet.jpg`**: A photo oriented horizontally/sideways (to test the 90° rotation tool).
8. **Connected Webcam or USB Document Camera**: For testing live video capture in `TC-PIPE-09`.
